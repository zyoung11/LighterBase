# Pricing界面中英文切换功能实现总结

## 实现的功能

### 1. HTML文件修改 (pricing.html)
- 为需要翻译的文本元素添加了 `data-i18n` 属性
- 删除了重复的DOM加载事件，只保留必要的FOUC修复
- 音乐控制按钮使用i18n动态更新文本

### 2. TypeScript文件修改 (hubConponents.ts)
- 在 `translatePage()` 函数中添加了pricing页面的特殊处理
- 音乐控制按钮文本会根据当前语言自动更新
- 语言切换时重新翻译整个页面

### 3. 支持的翻译键值
根据lang文件夹中的语言文件，支持以下翻译：

#### 标题部分 (pricing.title)
- `pricing.title.free`: "Totally Free!!" / "完全免费！！"

#### 副标题部分 (pricing.subtitle)
- `pricing.subtitle.efficient`: "Open and Efficent" / "开放且高效"

#### 音乐控制部分 (pricing.music)
- `pricing.music.play`: "▶️" / "▶️"
- `pricing.music.pause`: "⏸️" / "⏸️"

## 实现细节

### 1. 翻译机制
- 使用 `data-i18n` 属性标记需要翻译的元素
- 通过 `i18n.t(key)` 函数获取对应语言的文本
- 音乐控制按钮有特殊的处理逻辑

### 2. 音乐控制功能
- 播放/暂停按钮文本会根据当前语言更新
- 点击按钮时切换播放状态和按钮文本
- 支持背景音乐播放控制

### 3. 动画效果
- 保留了原有的扫描线动画效果
- 保留了二进制背景和鼠标交互效果
- 保留了音乐播放时的显示/隐藏逻辑

## 使用方法

### 1. 语言切换
- 用户可以通过右上角的语言切换按钮（"中"/"EN"）切换语言
- 语言设置会自动保存到localStorage
- 页面内容会实时更新为对应语言

### 2. 音乐控制
- 点击音乐控制按钮可以播放/暂停背景音乐
- 按钮文本会根据当前语言显示
- 音乐控制按钮会在文本显示动画结束后出现

### 3. 添加新的翻译文本
1. 在 `lang/en.json` 和 `lang/zh.json` 中添加对应的翻译键值
2. 在HTML中为需要翻译的元素添加 `data-i18n` 属性
3. 翻译会自动生效

## 注意事项

1. 音乐控制按钮的文本是动态更新的，需要在翻译函数中特殊处理
2. 保留了原有的所有动画和交互效果
3. 语言切换会影响整个页面的文本内容
4. 音乐播放状态在语言切换时会保持不变

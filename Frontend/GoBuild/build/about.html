项目简介

Go Fiber Web 服务器是一个基于 Go Fiber 框架构建的高性能 Web 服务器，专门设计用于快速部署静态网站和单页应用。

该项目采用现代化的 Go 语言开发，结合 Fiber 框架的高性能特性，提供了简单易用的静态文件服务和路由配置功能。

技术栈

Go Fiber

高性能 HTTP 框架

Go 1.25+

编程语言

Embed FS

文件嵌入系统

JSON 配置

路由配置文件

主要特性

  • ⚡ 极快的响应速度，基于 Fiber 框架的高性能特性
  • 📁 自动服务 build 目录下的静态文件
  • 🛣️ 通过 routes.json 文件配置自定义路由
  • 🔧 支持中间件：压缩、ETag、文件系统缓存
  • 🚀 单文件部署，无需额外依赖
  • 📱 响应式设计，支持移动设备
  • 🔒 内置安全特性，防止目录遍历攻击
  • ⚙️ 易于配置和扩展

使用方法

1. 将 HTML、CSS、JS 等静态文件放入 build 目录

2. 在 routes.json 中配置路由映射

3. 运行 go build 编译程序

4. 执行生成的可执行文件启动服务器

默认服务器运行在端口 8090，可通过浏览器访问 http://localhost:8090
